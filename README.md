PLK UNIVERSITY STUDENT INFORMATION SYSTEM
FINAL CAPSTONE PROJECT

Integrated Student Information & Mobile Analytics Ecosystem for PLK University, a community built on the belief that every learner should be equal, confident, and radiant, with a sharp mind and a generous heart.
Our system connects a Windows desktop dashboard with live ScottPlot charts and a mobile directory app built in .NET MAUI, both sharing one MySQL database.
Administrators can see how students are distributed across the university's programs, while the mobile app lets users search and browse student records anywhere.
The project reflects the university's charter. It respects privacy and consent by handling student information carefully and validating every input.
It upholds honesty and integrity through a transparent GitHub history that credits every member's work.
It also supports the university's mission of using intelligence for the good of the community by giving the campus a tool that is simple, reliable, and easy to use.
